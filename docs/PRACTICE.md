# 练习指南 · 怎么用这个靶场

## 三条推荐路径

### 1. 手工挖（推荐新手）

```bash
python app.py 8095
# 浏览器打开 http://127.0.0.1:8095，首页有全部入口
```

打开 `LAB-MANIFEST.md` 看"漏洞清单"前，**先自己试着找一遍**，把发现写下来再对照——
这比直接看答案有意义得多。

### 2. 自动化工具实战

靶场的作用是给自动化工具提供**可控、可重置、可反复打**的目标：

```bash
# 用任意爬虫/扫描器指向 http://127.0.0.1:8095
# 每轮打完一键复位，回到干净状态
curl -X POST "http://127.0.0.1:8095/__reset?confirm=RESET"
```

### 3. 盲挖考核（去提示化）

如果你要评估"**在没有任何提示的情况下能否独立发现漏洞**"，直接对着本仓库练是不准的
（清单和页面把漏洞类别写在了脸上）。建议：

1. Fork 本仓库，删掉 `LAB-MANIFEST.md` 与 README 里的漏洞清单
2. 把语义化变量名/路由名改成无意义名字（`vuln01` → `a1q` 之类）
3. 再让别人（或未来的自己）对着改过的版本打一遍，记录耗时与命中率

## 复位与环境

| 操作 | 命令 |
| --- | --- |
| 启动（默认 8095） | `python app.py` |
| 换端口 | `python app.py 9001` |
| 进程内重置 | `python app.py --reset` |
| HTTP 重置（仅回环来源 + POST + confirm=RESET） | `curl -X POST "http://127.0.0.1:8095/__reset?confirm=RESET"` |

首次启动会自动建库、写种子数据、生成 `config.bak` 与 `uploads/`。
